# 📝 Day 02 — Creating Arrays: Practice Tasks

**Estimated time:** 25–35 minutes

## 🎯 Goal

Practice different ways to create NumPy arrays and understand when to use each method.

---

## Task 1 — Basic Array

Create a NumPy array containing:

```text
5, 10, 15, 20, 25
```

Print the array.

---

## Task 2 — Two-Dimensional Array

Create the following 2D array:

```text
[[1, 2, 3],
 [4, 5, 6]]
```

Print the array.

### Question

How many rows and columns does this array have?

---

## Task 3 — Zeros Array

Create:

1. A one-dimensional array containing **5 zeros**.
2. A two-dimensional array containing **3 rows and 4 columns**, filled with zeros.

Print both arrays.

---

## Task 4 — Ones Array

Create:

1. A one-dimensional array containing **6 ones**.
2. A two-dimensional array with **2 rows and 3 columns**, filled with ones.

Print both arrays.
