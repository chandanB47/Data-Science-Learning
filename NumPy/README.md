# 🔢 NumPy for Data Science

A structured learning journey for mastering numerical computing, array operations, and data analysis using NumPy.

## 🎯 Learning Goal

Learn to efficiently work with numerical data using NumPy arrays, vectorized operations, filtering, and statistical functions.

## 📅 15-Day Learning Roadmap

| Day | Topic | Key Concepts |
| --- | --- | --- |
| 1 | NumPy Basics | NumPy, `ndarray`, Python lists vs arrays |
| 2 | Creating Arrays | `array()`, `zeros()`, `ones()`, `arange()`, `linspace()` |
| 3 | Array Properties | `shape`, `size`, `ndim`, `dtype` |
| 4 | Indexing & Slicing | Accessing elements, slicing, subarrays |
| 5 | Array Operations | Arithmetic operations and NumPy functions |
| 6 | Aggregation | `sum()`, `mean()`, `min()`, `max()`, `axis` |
| 7 | Boolean Indexing | Filtering arrays using conditions |
| 8 | Reshaping Arrays | `reshape()`, `flatten()`, transpose |
| 9 | Combining Arrays | Concatenation, stacking, splitting |
| 10 | Broadcasting | Operations with different array shapes |
| 11 | Vectorization | Efficient operations without Python loops |
| 12 | Random Data | Generating random datasets |
| 13 | Statistical Analysis | Standard deviation, percentiles, correlation |
| 14 | Revision & Practice | Solve data analysis problems |
| 15 | Final Project | NumPy Data Analysis Project |
