# Day 10 — Power Query (ETL)

## 📌 Overview
Power Query is Excel’s data preparation tool for importing, cleaning, transforming, combining, and refreshing data through repeatable steps.

## 🎯 Learning Objectives
- Understand ETL: Extract, Transform, Load.
- Import Excel data into Power Query.
- Set data types and clean inconsistent values.
- Add calculated columns.
- Merge and append queries.
- Unpivot data.
- Inspect Applied Steps and introductory M code.
- Refresh query outputs.

## 🧰 Skills Practiced
- Power Query Editor
- Data type management
- Text cleanup and value replacement
- Custom columns
- Merge Queries and Append Queries
- Unpivot Columns
- Query refresh
- M language basics
