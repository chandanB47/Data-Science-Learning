# Day 06 — Data Cleaning & Validation
---

### 📌 Overview

- Day 06 focuses on Data Cleaning and Data Validation in Microsoft Excel.

- Real-world datasets often contain extra spaces, inconsistent text, duplicate records, blank values, and invalid entries.

- For this practice, use the same 10K sales dataset used throughout the Excel module.

---

### 🎯 Learning Objectives

    By the end of Day 06, you will be able to:
    
    Clean inconsistent text data
    
    Remove extra spaces
    
    Split data into multiple columns
    
    Identify and remove duplicates
    
    Find blank/missing values
    
    Standardize inconsistent values

    Create Data Validation rules
    
    Build a basic Data Quality Audit
