### 🎯 Learning Objectives

By the end of Day 04, I should be able to:

- Use IF for simple business decisions.
- Combine conditions using AND.
- Use OR when any one of several conditions is sufficient.
- Use IFS for multiple categories.
- Use SWITCH for fixed-value classification.
- Handle formula errors using IFERROR.
- Detect missing values using ISBLANK.
- Build automated business rules.
- Calculate employee commissions.
- Classify sales transactions.
