# Day 09 — Dashboards & Visualization
---

## 📌 Overview

 Day 09 focuses on transforming Excel analysis into a professional Executive Sales KPI Dashboard.

 You will use the same 10,000-record Sales dataset from previous days and build a management-style dashboard containing KPI cards, charts, sparklines, filters, and business insights.

- Dataset: raw_data.xlsx
- Sheet: Sales_Data
---

### 🎯 Learning Objectives

#### By the end of Day 09, you should be able to:

  - Design a professional Excel dashboard
  - Create KPI cards
  - Calculate important business metrics
  - Create dynamic charts
  - Use Combo Charts
  - Use Sparklines
  - Add interactive filters
  - Compare sales performance
  - Visualize trends
  - Present business insights clearly
  - Build an Executive KPI Dashboard
