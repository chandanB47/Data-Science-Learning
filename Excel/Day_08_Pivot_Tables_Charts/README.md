# Day 08 — Pivot Tables & Charts

---
### 📌 Overview

- Day 08 focuses on analyzing large datasets using Pivot Tables, Pivot Charts, Grouping, Slicers, Timelines, and Percentage of Total calculations.

- Using the same 10,000-record Sales dataset, you will convert raw transaction data into meaningful business insights.

    - Dataset: raw_data.xlsx
  
    - Sheet: Sales_Data

### 🎯 Learning Objectives

#### By the end of Day 08, you should be able to:

- Create Pivot Tables from a large dataset
- Configure Rows, Columns, Values, and Filters
- Summarize data using Sum, Count, and Average
- Group dates by Month and Year
- Calculate % of Grand Total
- Add and use Slicers
- Add and use a Timeline
- Create Pivot Charts
- Analyze sales by Region, Product, Category, Channel, and Status
- Build an E-Commerce Sales Analysis
