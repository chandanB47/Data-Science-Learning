# Day 11 — Power Pivot & Data Modeling

## 📌 Overview
Build a relational Excel Data Model from the sales workbook and use DAX measures and Data Model PivotTables to analyze business performance.

## 🎯 Learning Objectives
- Identify fact and dimension tables.
- Design and validate a star schema.
- Load tables into the Excel Data Model.
- Create relationships using matching key fields.
- Understand calculated columns, measures, and filter context.
- Write DAX using `SUM`, `COUNTROWS`, `DISTINCTCOUNT`, `DIVIDE`, `CALCULATE`, and `RELATED`.
- Build PivotTables/PivotCharts from the Data Model.
