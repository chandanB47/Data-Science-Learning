# Day 07 — Conditional Formatting & Sorting

---
### 📌 Overview

Day 07 focuses on Conditional Formatting, Sorting, Filtering, and KPI Risk Tracking in Microsoft Excel.

These features help Data Analysts quickly identify high and low sales, poor-performing transactions, risk conditions, KPIs, patterns, and outliers.

Use the same 10K sales dataset used throughout the Excel module.

---
### 🎯 Learning Objectives

      - By the end of Day 07, you will be able to:
      - Apply Conditional Formatting
      - Create custom Conditional Formatting rules
      - Use Color Scales
      - Highlight top and bottom values
      - Sort data using multiple conditions
      - Filter data based on business requirements
      - Create KPI-based risk indicators
      - Build a simple Risk Tracker
