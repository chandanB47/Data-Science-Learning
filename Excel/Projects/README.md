# 📌 Projects

## Project 01 --- Sales Performance Dashboard

**Status:** ✅ Completed

An Excel-based sales analytics project that transforms raw sales
transaction data into structured analysis tables, KPIs, charts, and an
executive-style dashboard.

### 🔍 Main Analysis

-   Gross Sales by Region
-   Top 5 Products by Gross Sales
-   Gross Sales by Category
-   Gross Sales by Sales Channel
-   Quantity Sold by Channel
-   Category-wise Quantity
-   Sales Contribution by Channel
-   Completed Sales
-   Cancelled Transactions

### 📊 Dashboard KPIs

-   Total Gross Sales
-   Total Quantity
-   Total Transactions
-   Average Transaction Value
-   Completed Sales
-   Cancelled Transactions

### 🛠️ Excel Concepts Used

-   `SUMIF()`
-   `COUNTIF()`
-   `AVERAGEIF()`
-   `SUMPRODUCT()`
-   `TRIM()`
-   Data Cleaning
-   Data Validation
-   Sorting and Filtering
-   Conditional Formatting
-   Number Formatting
-   Chart Creation
-   KPI Cards
-   Dashboard Layout
