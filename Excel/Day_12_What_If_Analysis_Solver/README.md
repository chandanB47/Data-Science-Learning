# Day 12 — What-If Analysis & Solver

## 📌 Overview
Explore how changes in business assumptions affect sales, costs, revenue, and profit using Excel What-If Analysis tools.

## 🎯 Learning Objectives
- Use Goal Seek to find an input needed to reach a target result.
- Build one-variable and two-variable Data Tables.
- Create and compare Scenarios with Scenario Manager.
- Set up an optimization model for Solver.
- Define objective cells, changing cells, and constraints.
- Interpret results and explain business trade-offs.

## 🧠 Key Concepts
- **What-If Analysis:** tests how changing inputs affects calculated outputs.
- **Goal Seek:** works backward from a target formula result to find one input value.
- **Data Table:** evaluates a formula across a range of one or two input values.
- **Scenario Manager:** saves and compares named sets of assumptions.
- **Solver:** optimizes an objective subject to constraints (availability depends on Excel edition/add-in).
