# 📅 Day 01: DBMS vs RDBMS & SQL Fundamentals

## 📌 Overview
Day 01 introduces database management system architectures, the core differences between flat DBMS and relational RDBMS systems, the ACID transaction model, and basic relational table design.

---

## 🎯 Key Learning Objectives
- [x] Understand the difference between file-based DBMS and relational RDBMS.
- [x] Master the **ACID** properties (Atomicity, Consistency, Isolation, Durability).
- [x] Identify core relational database components (Tables, Primary Keys, Foreign Keys).
- [x] Categorize the 5 main SQL sub-languages (DDL, DML, DQL, TCL, DCL).
- [x] Write baseline schema definitions with referential integrity constraints.
