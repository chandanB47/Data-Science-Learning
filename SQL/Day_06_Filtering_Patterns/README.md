# 📅 Day 06: Filtering & Pattern Matching

## 📌 Overview
Day 06 focuses on filtering data using the `WHERE` clause, combining logical expressions, performing range evaluations, checking memberships, and matching text patterns with wildcards.

---

## 🎯 Key Learning Objectives
- [x] Restrict row output precisely using comparison operators (`=`, `!=`, `<>`, `>`, `<`, `>=`, `<=`).
- [x] Combine conditional logic with Boolean operators (`AND`, `OR`, `NOT`).
- [x] Query value ranges efficiently using `BETWEEN ... AND`.
- [x] Perform discrete set lookups with `IN` and `NOT IN`.
- [x] Match string patterns using `LIKE`, `ILIKE` (case-insensitive), and wildcards (`%`, `_`).
- [x] Filter missing values accurately using `IS NULL` and `IS NOT NULL` (avoiding `= NULL`).
