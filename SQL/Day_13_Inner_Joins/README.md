# 📅 Day 13: Inner Joins & Relational Mapping

## 📌 Overview
Day 13 covers relational data querying using `INNER JOIN`. This day focuses on how relational schemas connect primary keys and foreign keys, joining multiple related tables simultaneously, eliminating ambiguous column references, and filtering matched records.

---

## 🎯 Key Learning Objectives
- [x] Understand relational theory and why data is normalized across multiple tables.
- [x] Master the syntax and behavior of `INNER JOIN` with the `ON` condition.
- [x] Prevent column ambiguity by using table aliases and fully qualified column names (`table.column`).
- [x] Connect three or more tables in a single relational join pipeline.
- [x] Compare modern ANSI `JOIN ... ON` syntax against legacy implicit comma joins.
- [x] Combine `INNER JOIN` with `WHERE`, `GROUP BY`, and aggregate functions.
