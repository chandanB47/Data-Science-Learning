# 🛒 Day 29: Project 1 - E-Commerce Analytics & RFM Segmentation

## 📌 Overview
Day 29 is a comprehensive end-to-end analytics project. You will design a production-grade relational e-commerce transactional database, analyze conversion and sales breakdowns, and build an advanced Recency, Frequency, Monetary (RFM) customer segmentation model using CTEs and statistical window functions (`NTILE`).

---

## 🎯 Key Project Deliverables
- [x] Normalized 3NF e-commerce schema with strict integrity constraints.
- [x] Category and channel sales breakdown with revenue and unit economics.
- [x] Repeat purchase rate and customer lifetime value (CLV) estimation.
- [x] Full statistical RFM (Recency, Frequency, Monetary) segmentation.
- [x] Actionable customer tier tagging (Champions, Loyal Customers, At Risk, Lost).
- [x] Product return rate and refund impact analysis.
