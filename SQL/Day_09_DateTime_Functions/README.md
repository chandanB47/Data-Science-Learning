# 📅 Day 09: Date & Time Operations

## 📌 Overview
Day 09 focuses on handling temporal data types, extracting date parts, performing date arithmetic, computing intervals, and formatting timestamps for reporting and time-series analysis.

---

## 🎯 Key Learning Objectives
- [x] Understand temporal data types (`DATE`, `TIME`, `TIMESTAMP`, `TIMESTAMPTZ`, `INTERVAL`).
- [x] Retrieve system date and time stamps (`CURRENT_DATE`, `CURRENT_TIMESTAMP`, `NOW()`).
- [x] Extract specific parts of timestamps using `EXTRACT()` and `DATE_PART()`.
- [x] Perform date arithmetic (adding/subtracting days, months, and years).
- [x] Calculate differences between dates (tenure, delivery durations, age).
- [x] Format and parse dates for reporting using `TO_CHAR()` and `DATE_FORMAT()`.
- [x] Truncate timestamps to standard analytical intervals using `DATE_TRUNC()`.
