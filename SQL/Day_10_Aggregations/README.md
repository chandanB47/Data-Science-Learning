# 📅 Day 10: Aggregate Functions & NULL Handling

## 📌 Overview
Day 10 explores SQL aggregate functions, which process multiple rows of data to produce a single summary metric. This day emphasizes standard calculations, duplicate elimination inside aggregations, and the critical rules governing `NULL` values.

---

## 🎯 Key Learning Objectives
- [x] Compute summary statistics using `COUNT()`, `SUM()`, `AVG()`, `MIN()`, and `MAX()`.
- [x] Distinguish between `COUNT(*)`, `COUNT(column)`, and `COUNT(DISTINCT column)`.
- [x] Understand the universal rule of aggregate functions regarding `NULL` values (automatic exclusion).
- [x] Calculate conditional metrics without subqueries using `CASE WHEN` inside aggregate functions.
- [x] Combine multiple aggregate functions into comprehensive metric summary tables.
