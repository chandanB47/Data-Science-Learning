# 📅 Day 16: Set Operators (UNION, UNION ALL, INTERSECT, EXCEPT)

## 📌 Overview
Day 16 covers SQL set theory operators used to combine, compare, and isolate result sets across multiple queries vertically, contrasting with horizontal table joins.

---

## 🎯 Key Learning Objectives
- [x] Understand mathematical set operations in relational databases.
- [x] Combine datasets using `UNION` (deduplicated) and `UNION ALL` (performance-optimized).
- [x] Find shared records using `INTERSECT`.
- [x] Isolate set differences using `EXCEPT` (or `MINUS` in Oracle).
- [x] Master the two strict structural rules for set operations (matching column counts and compatible data types).
- [x] Implement pagination and ordering with `ORDER BY` on combined sets.
