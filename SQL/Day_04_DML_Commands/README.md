# 📅 Day 04: DML (Data Manipulation Language)

## 📌 Overview
Day 04 covers data manipulation techniques in SQL, focusing on inserting individual and bulk records, conditionally updating rows, deleting targeted records, and leveraging atomic write patterns.

---

## 🎯 Key Learning Objectives
- [x] Master single-row and multi-row insertions with `INSERT INTO`.
- [x] Insert query results dynamically using `INSERT INTO ... SELECT`.
- [x] Update targeted data safely using `UPDATE` with explicit `WHERE` filters.
- [x] Remove targeted records precisely using `DELETE`.
- [x] Understand the performance implications and logging differences between DML and DDL operations.
- [x] Handle write conflicts using upsert strategies (`ON CONFLICT` / `ON DUPLICATE KEY UPDATE`).
