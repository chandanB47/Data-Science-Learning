# Day 21: Window Functions I (Ranking & Numbering)

## 🎯 Key Learning Objectives
* Understand what a window function is and how it preserves row-level details.
* Master the `OVER()` clause, `PARTITION BY`, and window `ORDER BY`.
* Differentiate between `ROW_NUMBER()`, `RANK()`, and `DENSE_RANK()` during tie scenarios.
* Segment observations into statistical percentiles or quartiles with `NTILE(k)`.
* Implement Top-N queries per category without subquery performance degradation.
