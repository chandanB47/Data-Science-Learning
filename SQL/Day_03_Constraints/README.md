# 📅 Day 03: SQL Constraints & Data Integrity

## 📌 Overview
Day 03 covers the implementation and management of SQL constraints used to enforce entity integrity, referential integrity, and domain rules at the database engine level.

---

## 🎯 Key Learning Objectives
- [x] Understand why database-level constraints are critical for data integrity.
- [x] Implement **PRIMARY KEY** and **FOREIGN KEY** (Referential Integrity).
- [x] Configure Foreign Key actions (`ON DELETE CASCADE`, `ON DELETE SET NULL`, `ON DELETE RESTRICT`).
- [x] Enforce uniqueness with **UNIQUE** and handle missing values with **NOT NULL**.
- [x] Define custom business logic rules using **CHECK** constraints.
- [x] Supply fallback values using **DEFAULT**.
- [x] Add, drop, and inspect named constraints on existing tables using `ALTER TABLE`.
