# 📅 Day 05: DQL & Basic Querying

## 📌 Overview
Day 05 focuses on Data Query Language (DQL) fundamentals, covering column projection, duplicate suppression, expression aliasing, scalar calculations, and the internal SQL query execution order.

---

## 🎯 Key Learning Objectives
- [x] Retrieve specific attributes and complete entity records using `SELECT`.
- [x] Eliminate duplicate rows in output sets using `DISTINCT` and multi-column `DISTINCT`.
- [x] Assign meaningful column and table aliases using `AS`.
- [x] Perform computed column calculations and string concatenations inline.
- [x] Handle missing values safely using `COALESCE` and `IFNULL` / `NVL`.
- [x] Master the logical execution order of an SQL query.
