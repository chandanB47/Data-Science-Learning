# 📅 Day 25: DCL & Database Security

---

## 📌 Overview
* Day 25 covers Data Control Language (DCL) and role-based access control (RBAC) in MySQL. 
* You will learn how to create users, assign least-privilege permissions, grant administrative rights, revoke access, and manage security roles for data teams.

---
## 🎯 Key Learning Objectives
- [x] Create and manage database user accounts with host-level scoping ('username'@'host').
- [x] Understand user authentication and password management using ALTER USER.
- [x] Assign granular object and global privileges using GRANT.
- [x] Remove explicit permissions using REVOKE.
- [x] Inspect active permissions using SHOW GRANTS.
- [x] Implement Role-Based Access Control (RBAC) by creating, assigning, and activating roles.
- [x] Apply the Principle of Least Privilege (PoLP) to secure production environments.
