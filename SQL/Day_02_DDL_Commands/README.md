# 📅 Day 02: DDL (Data Definition Language)

## 📌 Overview
Day 02 focuses on defining, altering, renaming, and destroying database structures using standard Data Definition Language (DDL) commands.

---

## 🎯 Key Learning Objectives
- [x] Create databases, schemas, and relational tables using `CREATE`.
- [x] Modify existing schemas (add, rename, drop, modify columns) using `ALTER`.
- [x] Rename database objects safely with `RENAME`.
- [x] Clear data instantly while preserving schema structure using `TRUNCATE`.
- [x] Completely eliminate database objects using `DROP`.
- [x] Understand the difference between `DELETE`, `TRUNCATE`, and `DROP`.
