# 📅 Day 08: String & Scalar Functions

## 📌 Overview
Day 08 focuses on transforming, formatting, cleaning, and extracting text data using built-in scalar and string functions in SQL.

---

## 🎯 Key Learning Objectives
- [x] Combine text fields using `CONCAT()` and the concatenation operator `||`.
- [x] Standardize casing with `UPPER()`, `LOWER()`, and `INITCAP()`.
- [x] Clean dirty input strings using `TRIM()`, `LTRIM()`, and `RTRIM()`.
- [x] Calculate string sizes using `LENGTH()` and `CHAR_LENGTH()`.
- [x] Extract target substrings using `SUBSTRING()` / `SUBSTR()`.
- [x] Replace and modify text using `REPLACE()` and `TRANSLATE()`.
- [x] Pad text for standard fixed-width reporting using `LPAD()` and `RPAD()`.
- [x] Round, truncate, and transform numbers using scalar math functions (`ROUND()`, `CEIL()`, `FLOOR()`, `ABS()`).
