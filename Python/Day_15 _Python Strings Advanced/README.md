# Day 15 — Python Strings Advanced

📌 **Overview**

Day 15 covers advanced string manipulation techniques in Python. 

Strings are immutable sequences of Unicode characters that serve as the foundation for data cleaning, text parsing, log analysis, and Natural Language Processing (NLP) in Data Science.

Mastering advanced string methods enables you to extract structured features from raw text, sanitize user inputs, and format data cleanly for analytical pipelines.

---

📚 **Topics Covered**

* Advanced Slicing & Striding (`[::-1]`, `[start:stop:step]`)
* Whitespace & Character Stripping (`strip()`, `lstrip()`, `rstrip()`)
* Splitting & Joining (`split()`, `rsplit()`, `join()`)
* Case Conversions (`upper()`, `lower()`, `title()`, `capitalize()`, `swapcase()`)
* Substring Searching & Counting (`find()`, `rfind()`, `index()`, `count()`)
* Prefix & Suffix Checking (`startswith()`, `endswith()`, `removeprefix()`, `removesuffix()`)
* String Validation Methods (`isdigit()`, `isalpha()`, `isalnum()`, `isspace()`)
* Dynamic String Formatting with `f-strings` & Specifiers
