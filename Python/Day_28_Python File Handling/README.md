# Day 28 — Python File Handling

📌 **Overview**

Day 28 explores input and output (I/O) operations using Python's built-in file handling capabilities.

Reading, parsing, and writing text or raw data files is a core competency in Data Science and Analytics. Whether ingesting raw server logs, exporting analytical summary reports, or persisting processed metrics to disk, mastering file pointers, modes, encodings, and context managers ensures safe, memory-conscious operations without data corruption or resource leaks.

---

📚 **Topics Covered**

* Built-in `open()` function and file access modes (`r`, `w`, `a`, `x`, `b`, `+`)
* The `with` statement and Context Managers (automatic cleanup)
* Reading mechanisms: `.read()`, `.readline()`, `.readlines()`, and line-by-line streaming
* Writing mechanisms: `.write()`, `.writelines()`
* File cursor manipulation using `.tell()` and `.seek()`
* Text encodings (`encoding="utf-8"`) and handling unicode characters
* Validating file existence and path operations with `os.path` and `pathlib`
* Memory-efficient processing of large text files
