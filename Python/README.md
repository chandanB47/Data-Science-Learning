## 🧠 How I Practice

For each topic, I aim to:

1.  Learn the concept and syntax.
2.  Write examples and run them.
3.  Solve practice questions independently.
4.  Review errors and improve the code.
5.  Save useful outputs or solutions.
6.  Apply the concept in projects when appropriate.
