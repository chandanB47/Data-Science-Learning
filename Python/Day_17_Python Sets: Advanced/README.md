# Day 17 — Python Sets: Advanced

📌 **Overview**

Day 17 focuses on advanced operations, mathematical set theory, and real-world data science applications using Python Sets (`set` and `frozenset`).

Sets are mutable, unordered collections of unique, hashable elements. Because they rely on internal hash tables, membership testing (`in`), insertions, and deletions run in average O(1) time complexity.

In Data Science, sets are widely used for deduplication, tracking unique identifiers, computing overlaps between customer cohorts, and performing fast transactional filtering.

---

📚 **Topics Covered**

* Adding & Updating elements (`add()`, `update()`)
* Removing elements safely (`remove()` vs `discard()`, `pop()`, `clear()`)
* Mathematical Set Operations (Union, Intersection, Difference, Symmetric Difference)
* Operators vs Methods (`|`, `&`, `-`, `^`)
* Set Relationship Checks (`issubset()`, `issuperset()`, `isdisjoint()`)
* Set Comprehensions (`{x for ...}`)
* Immutable Sets (`frozenset`)
* Real-world Data Science use cases (Cohort overlap, vocabulary extraction, deduplication)
