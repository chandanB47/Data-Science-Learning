# Day 21 — Functions Advanced

📌 **Overview**

Day 21 kicks off Phase 2: Functions & Modular Python. 

Functions in Python are first-class citizens. Writing robust, maintainable, and modular data pipelines requires moving beyond basic function declarations to understand parameter definitions, keyword argument mapping, default parameter caveats, enforcement mechanics, and multi-value returns.

---

📚 **Topics Covered**

* Parameters vs. Arguments
* Positional vs. Keyword Arguments
* Default Parameter Values & The Mutable Default Argument Trap
* Keyword-Only Arguments (using `*`)
* Positional-Only Arguments (using `/`)
* Functions returning multiple values (tuple packing & unpacking)
* Docstrings (`PEP 257`) & Type Hinting (`PEP 484`)
