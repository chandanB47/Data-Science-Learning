# Day 31 — Classes & Objects

📌 **Overview**

Day 31 kicks off Phase 4: Object-Oriented Programming (OOP) in Python.

OOP is a programming paradigm that organizes code into reusable blueprints called **Classes**, which bundle state (attributes) and behavior (methods) into concrete instances called **Objects**.

In Data Science, OOP is the structural foundation for:
* Machine Learning estimators and transformers (e.g., scikit-learn's `.fit()` and `.predict()`)
* Deep Learning custom layers and neural network models (e.g., PyTorch `nn.Module`)
* Data preprocessing pipelines, database connectors, and feature stores

---

📚 **Topics Covered**

* What is a Class vs. an Object (Blueprint vs. Instance)
* Defining a class with the `class` keyword
* Instantiating objects from a class
* Instance attributes vs. Class-level attributes
* Instance methods and the explicit `self` parameter
* Modifying and querying object state at runtime
* Inspecting objects with `type()`, `isinstance()`, and `__dict__`
* Simulating a basic ML estimator class (`Estimator`)
