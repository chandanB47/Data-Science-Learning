# Day 30 — Working with JSON Data

📌 **Overview**

Day 30 completes Phase 3: Error Handling & Files by mastering JavaScript Object Notation (JSON) using Python's standard `json` module.

JSON is the ubiquitous data interchange format across web APIs, document databases (MongoDB), cloud configurations, and machine learning pipeline metadata. Unlike flat CSVs, JSON natively supports hierarchical nested representations, key-value mappings, arrays, and boolean logic.

Mastering JSON serialization, deserialization, custom schema mapping, and file I/O prepares you for modern data ingestion and API communication in Data Science.

---

📚 **Topics Covered**

* JSON syntax specification vs. Python native data structures
* Serialization (Encoding): `json.dumps()` (to string) and `json.dump()` (to file)
* Deserialization (Decoding): `json.loads()` (from string) and `json.load()` (from file)
* Formatting and readability: `indent`, `sort_keys`, and `separators`
* Handling non-serializable objects (datetime, sets, custom classes) using `default=`
* Parsing deeply nested API responses
* Validating, merging, and updating persistent JSON files
* Pruning, normalizing, and flattening nested JSON trees
