# Day 18 — Tuples & Unpacking

📌 **Overview**

Day 18 focuses on Python Tuples (`tuple`), their immutability, structural advantages, and unpacking patterns.

Tuples are ordered, immutable sequences. Because they cannot be modified after creation, they provide data integrity, consume less memory than lists, and are hashable (meaning they can serve as dictionary keys or set elements if they contain immutable items).

In Data Science, tuples are widely used for returning multiple values from functions, storing fixed records (e.g., coordinates, database rows, RGB values), and structured sequence unpacking.
