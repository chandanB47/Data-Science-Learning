# Day 12 - Python Range and Loop Practice

## 📌 Overview

Day 12 focuses on Python's range() function and its practical use with for loops.

The goal is to understand how to generate sequences of numbers, control the starting point, ending point, and step value, and combine range() with conditions, functions, and calculations.

---

## 📚 Topics Covered

- Python range()
- range(stop)
- range(start, stop)
- range(start, stop, step)
- Positive step
- Negative step
- range() with for loop
- range() with if
- Multiplication tables
- Calculating sums
- range() with functions
- Looping through a sequence of numbers
