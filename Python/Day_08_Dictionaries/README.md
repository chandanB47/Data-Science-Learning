## 📝 Key Learning

- Dictionaries store data as key-value pairs.
- Keys must be unique.
- Dictionaries are mutable.
- Values can contain different data types.
- Dictionaries are useful for representing structured records.

## 🔗 Data Science Connection

Dictionaries are useful for:

- Representing records
- Storing configuration data
- Working with JSON data
- Preparing structured data
- Representing API responses
- Storing key-value information

Example:

```python
student = {
    "name": "Chandan",
    "age": 26,
    "course": "Data Science"
}
```
