# Day 26 — Recursion

📌 **Overview**

Day 26 explores Recursion, an algorithmic technique where a function solves a problem by calling smaller instances of itself until reaching a termination state.

In Data Science and Machine Learning, recursion is the core computational model driving tree traversals (Decision Trees, Random Forests, Gradient Boosted Trees), divide-and-conquer partition schemes (QuickSort, MergeSort), and hierarchical data structures (directory trees, nested JSON object parsing).

---

📚 **Topics Covered**

* What is Recursion & How the Call Stack Works
* The Two Mandatory Pillars: **Base Case** and **Recursive Step**
* Classic Recursion: Factorial & Fibonacci Sequence
* Stack Overflows & Python's Recursion Limit (`sys.getrecursionlimit()`)
* Divide-and-Conquer Algorithms (Binary Search, MergeSort)
* Traversing Deeply Nested Arbitrary JSON/Dictionaries
* Recursion with Memoization (`functools.lru_cache`)
* When to Use Recursion vs. Iterative Loops
