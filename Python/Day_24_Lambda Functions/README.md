# Day 24 — Lambda Functions

📌 **Overview**

Day 24 explores Python Lambda Functions (anonymous, inline functions). 

A lambda function is a small, throwaway function defined without a name using the `lambda` keyword. In Data Science and Analytics, lambdas are essential for passing ad-hoc transformations into higher-order functions, custom sorting routines (`sorted()`, `.sort()`), and pandas vectorization methods (`.apply()`, `.map()`).

---

📚 **Topics Covered**

* Syntax of Lambda functions vs. Standard `def` functions
* Single-expression rules and implicit returns
* Lambdas with multiple arguments
* Conditional expressions (ternary operators) inside Lambdas
* Custom sorting and ranking using `key=lambda ...`
* Sorting complex structures (dictionaries, tuples, objects) by multiple criteria
* Closures using Lambda factories
* When to use Lambdas vs. when to write standard `def` functions
