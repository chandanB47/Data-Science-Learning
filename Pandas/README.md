# 🐼 Pandas for Data Science

A structured learning journey for mastering data cleaning, transformation, analysis, and exploratory data analysis.

## 🎯 Learning Goal

Learn to independently load, clean, transform, analyze, and summarize real-world datasets.

## 📅 Learning Roadmap — Days 57–91

| Phase | Days | Focus |
|---|---|---|
| Foundations | 57–63 | Series, DataFrames, loading and inspecting data |
| Selection & Filtering | 64–68 | Columns, rows, filtering, sorting |
| Data Cleaning | 69–75 | Missing values, duplicates, data types, text cleaning |
| Data Analysis | 76–81 | Counting, GroupBy, aggregation, pivot tables |
| Data Transformation | 82–86 | Concatenation, merging, dates, reshaping |
| Advanced Pandas | 87–90 | Apply, transform, rolling calculations, EDA |
| Final Project | 91 | Zomato Restaurant EDA |

## 📊 Key Skills

- Loading datasets
- Data inspection
- Data cleaning
- Filtering and sorting
- GroupBy and aggregation
- Merging datasets
- Date and time analysis
- Exploratory Data Analysis

## 🍽️ Final Project

### Zomato Restaurant EDA

An end-to-end data analysis project involving:

- Data inspection

- Exploratory data analysis
- Insights and conclusions

## 🎯 Final Goal

Analyze an unfamiliar dataset independently and communicate meaningful insights.
