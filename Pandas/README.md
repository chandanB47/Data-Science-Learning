# 🐼 Pandas for Data Science

A structured learning journey to master **Pandas for Data Analysis and Data Science** through daily lessons, hands-on practice, and real-world projects.

## 🎯 Learning Goal

Learn to independently:

- Load and inspect datasets
- Clean and transform data
- Filter and analyze information
- Perform aggregations and summaries
- Conduct Exploratory Data Analysis (EDA)
- Analyze real-world datasets and communicate insights

---

# 📅 Learning Roadmap — 35 Days

> This Pandas module is part of my overall Data Science learning roadmap.  
> The lessons in this folder are organized from **Day 01 to Day 35**.

## 🟢 Phase 1 — Foundations

| Day | Topic | Key Concepts |
|---|---|---|
| 01 | Pandas Introduction | Pandas, Series, DataFrames |
| 02 | Pandas Series | Creating, indexing, manipulating Series |
| 03 | Pandas DataFrames | Creating DataFrames and understanding structure |
| 04 | Loading Data | `read_csv()`, Excel files, dataset basics |
| 05 | Data Inspection | `head()`, `tail()`, `shape`, `columns` |
| 06 | Understanding Data | `info()`, `describe()`, data types |
| 07 | Revision Challenge | Dataset exploration challenge |

---

## 🔵 Phase 2 — Selection & Filtering

| Day | Topic | Key Concepts |
|---|---|---|
| 08 | Column Selection | Single and multiple columns |
| 09 | Row Selection | `.loc[]` and `.iloc[]` |
| 10 | Boolean Filtering | Filtering rows with conditions |
| 11 | Multiple Conditions | `&`, `\|`, complex filtering |
| 12 | Sorting Data | `sort_values()` and ranking |

---

## 🟡 Phase 3 — Data Cleaning

| Day | Topic | Key Concepts |
|---|---|---|
| 13 | Missing Data | `isnull()`, `notnull()` |
| 14 | Handling Missing Values | `dropna()`, `fillna()` |
| 15 | Duplicate Data | `duplicated()`, `drop_duplicates()` |
| 16 | Data Types | `astype()` and type conversion |
| 17 | Text Cleaning | Pandas `.str` methods |
| 18 | Renaming and Replacing | Column and value standardization |
| 19 | Data Cleaning Challenge | Clean a messy dataset |

## 🟠 Phase 4 — Data Analysis

| Day | Topic | Key Concepts |
|---|---|---|

| 21 | GroupBy Basics | Grouping and summarizing |
| 22 | Aggregation | `sum()`, `mean()`, `count()`, `min()`, `max()` |
| 23 | Multiple Aggregations | `.agg()` |
| 24 | Pivot Tables | Analytical summaries |
| 25 | Crosstab Analysis | Comparing categorical variables |

## 🟣 Phase 5 — Data Transformation
