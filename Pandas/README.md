# 🐼 Pandas for Data Science

A structured learning journey for mastering data cleaning, transformation, analysis, and exploratory data analysis using Pandas.

## 🎯 Learning Goal

Learn to independently load, clean, transform, analyze, and summarize real-world datasets.

## 📅 15-Day Learning Roadmap

| Day | Topic | Key Concepts |
| --- | --- | --- |
| 1 | Pandas Basics | Pandas, Series, DataFrames |
| 2 | Loading & Inspection | CSV, Excel, `head()`, `tail()`, `info()`, `describe()` |
| 3 | Data Selection | Columns, `.loc[]`, `.iloc[]` |
| 4 | Filtering | Boolean filtering, multiple conditions |
| 5 | Sorting & Counting | `sort_values()`, `value_counts()` |
| 6 | Missing Data | `isnull()`, `dropna()`, `fillna()` |
| 7 | Duplicates & Data Types | `duplicated()`, `drop_duplicates()`, `astype()` |
| 8 | Text Cleaning | `.str`, `rename()`, `replace()` |
| 9 | GroupBy | Grouping and summarizing data |
| 10 | Aggregation & Pivot Tables | `.agg()`, `pivot_table()` |
| 11 | Combining Data | `concat()`, `merge()`, join types |
| 12 | Date & Time | `to_datetime()`, `.dt` |
| 13 | Data Transformation | `apply()`, `map()` |
| 14 | Exploratory Data Analysis | Complete data analysis workflow |
| 15 | Final Project | End-to-end Pandas project |

## 💼 Entry-Level Readiness

This roadmap covers the core Pandas concepts needed for a strong foundation in Data Analysis and entry-level Data Science roles.

After completing this roadmap, I should be able to:

- Explore and understand unfamiliar datasets
- Clean and prepare data for analysis
- Filter and transform data efficiently
- Perform grouping and aggregation
- Combine multiple datasets using joins
- Conduct basic Exploratory Data Analysis
- Communicate meaningful insights from data

> **Note:** Completing the roadmap is not the same as mastering Pandas. You should be able to solve practical problems independently, explain why you selected a particular operation, and analyze unfamiliar datasets without following a tutorial.

Build a strong foundation in Pandas and confidently analyze real-world datasets independently.
