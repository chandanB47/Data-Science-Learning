# 📊 Power BI — Day 08: Rename, Split & Replace Columns

**Level:** Beginner  
**Day:** 8 of 30  
**Phase:** Level 2 — Power Query & Data Preparation  
**Dataset:** `PowerBI_Master_Sales_Dataset_1500.csv`

## 🎯 Day 8 Goal

Learn how to standardize and transform columns in Power Query using:

- Rename Columns
- Split Columns
- Replace Values
- Validate the transformed data

## 📚 Topics

### 1. Rename Columns
Learn to rename columns clearly and consistently for reporting.

### 2. Split Columns
Learn to split text using a delimiter or another suitable rule.

### 3. Replace Values
Learn to replace specific inconsistent values without changing unrelated data.

### 4. Validation
Check column names, split results, replacements, data types, row count, and overall data integrity.

Do not make transformations just to demonstrate a feature.

Every rename, split, or replacement should have a clear purpose. Always inspect the result after applying a transformation.
