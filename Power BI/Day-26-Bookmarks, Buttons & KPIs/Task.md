# Power BI — Day 26 TASK: Bookmarks, Buttons & KPIs

**Level:** Beginner to Intermediate  
**Estimated time:** 75–120 minutes

## Goal
Add functional navigation, KPI cards, and conditional formatting to your report.

## Part A — Open and save
- [ ] Open your completed Day 25 PBIX.
- [ ] Select **File → Save As**.
- [ ] Save as `Day26_Bookmarks_Buttons_KPIs.pbix`.

## Part B — Create a bookmark
- [ ] Go to the main report page.
- [ ] Set a useful slicer state, such as one region or year.
- [ ] Open **View → Bookmarks**.
- [ ] Add a bookmark named `Regional View`.
- [ ] Check bookmark options; enable Data if slicer selections should be saved.
- [ ] Change the slicer selection.
- [ ] Select the bookmark and verify that the saved view returns.

**Question:** What state does your bookmark restore?

## Part C — Add a functional button
- [ ] Insert a button.
- [ ] Enable **Action**.
- [ ] Choose **Page navigation** with a destination page or **Bookmark** with `Regional View`.
- [ ] Add a clear button label.
- [ ] Test the button in reading mode (often Ctrl+click in Desktop).

**Question:** What happens when you activate your button?

## Part D — Add or review KPI cards
Use existing measures where available:
- [ ] `[Total Net Sales]`
- [ ] `[Average Net Sales]`
- [ ] `[Unique Customers]`
- [ ] `[Net Sales YTD]`

- [ ] Add or review at least two relevant KPI cards.
- [ ] Give each card a clear title.
- [ ] Use consistent number formatting.
- [ ] Confirm slicers update KPI values.

Skip any KPI whose measure is unavailable; do not use an inaccurate substitute.

## Part E — Conditional formatting
- [ ] Select a table or matrix containing `[Total Net Sales]`.
- [ ] Apply background color, font color, or data bars to sales values.
- [ ] Check that formatting makes comparisons easier.
- [ ] Confirm text remains readable.
- [ ] Test formatting with a slicer selection.

**Question:** What does the conditional formatting help you notice?

## Part F — Final validation
- [ ] Bookmark restores the intended view.
- [ ] Button action works.
- [ ] KPI cards show valid measures.
- [ ] Slicers update KPIs.
- [ ] Conditional formatting is useful and readable.
- [ ] Overview navigation is clear.
- [ ] PBIX saved.
