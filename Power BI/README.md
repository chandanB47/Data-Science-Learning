# 📊 Power BI Learning Journey

A structured, day-by-day learning path to develop practical Power BI
skills for data analysis and build a portfolio of projects.

## 🎯 Learning Goal

Learn to prepare, model, analyze, and visualize data with Microsoft
Power BI, then publish well-documented dashboard projects as part of my
Data Science learning portfolio.
