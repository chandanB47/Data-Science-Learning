# 📊 Power BI Learning Journey

A structured **30-day, hands-on learning path** to develop practical Power BI skills for data analysis, dashboard development, and portfolio building.

This learning journey is part of my **Data Science Learning** roadmap. Power BI is being learned alongside an offline Power BI class, with additional hands-on practice, documentation, and GitHub portfolio work.

---

## 🎯 Learning Goal

Learn to:

- Import and prepare data using Power BI
- Clean and transform data using Power Query
- Build relationships and data models
- Write DAX measures and calculated columns
- Create interactive and professional dashboards
- Analyze business data and generate insights
- Document Power BI projects professionally
- Maintain Power BI work in GitHub as part of my Data Science portfolio

---

# 🧭 30-Day Learning Roadmap

| Phase | Days | Focus |
|---|---:|---|
| **Level 1 — Fundamentals** | 1–5 | Power BI ecosystem, Desktop interface, data import and report workflow |
| **Level 2 — Power Query** | 6–12 | Data cleaning, transformation, profiling, merge, append and aggregation |
| **Level 3 — Data Modeling** | 13–16 | Relationships, cardinality, star schema and modeling concepts |
| **Level 4 — DAX** | 17–21 | Measures, calculated columns, core DAX, CALCULATE and filter context |
| **Level 5 — Visualization** | 22–27 | Visuals, slicers, interactions, drill-through, bookmarks, KPIs and dashboard design |
| **Level 6 — Project & Portfolio** | 28–30 | Final project, validation, documentation and GitHub presentation |
