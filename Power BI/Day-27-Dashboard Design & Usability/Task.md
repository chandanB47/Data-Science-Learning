# Power BI — Day 27 TASK: Dashboard Design & Usability

**Level:** Beginner to Intermediate  
**Estimated time:** 75–120 minutes

## Goal
Polish your sales report into a clear, business-focused dashboard and verify that features from Days 22–26 still work.

## Part A — Open and save
- [ ] Open your completed Day 26 PBIX.
- [ ] Select **File → Save As**.
- [ ] Save as `Day27_Dashboard_Design_Usability.pbix`.

## Part B — Organize the page
- [ ] Add or refine a clear report title.
- [ ] Place key KPI cards near the top.
- [ ] Make the main sales comparison and trend visuals prominent.
- [ ] Place supporting tables/matrices lower on the page or on a separate page.
- [ ] Keep region and date/year slicers in a predictable location.
- [ ] Keep navigation buttons easy to find.

## Part C — Improve visual consistency
- [ ] Use consistent titles and fonts.
- [ ] Use consistent sales number formatting.
- [ ] Use a small, purposeful color palette.
- [ ] Align visual edges and keep spacing consistent.
- [ ] Ensure labels are readable at normal viewing size.
- [ ] Remove unnecessary legends, gridlines, borders, or decoration where they do not help.

## Part D — Test usability and features
- [ ] Region slicer works.
- [ ] Year/Date slicer works.
- [ ] Clearing slicers restores the full report.
- [ ] Bookmark restores the intended view.
- [ ] Button action works.
- [ ] Drill-down works.
- [ ] Drill-through opens the expected detail page.
- [ ] Back navigation works.
- [ ] Tooltips show useful information.
- [ ] Visual interactions behave as intended.

## Part E — Record three observations
Use actual values or patterns from your report:
1. Highest-selling category: ____________________
2. Sales trend observation: ____________________
3. Region/channel/product to investigate further: ____________________

Do not guess. If the report does not support an observation, note what additional data or visual is needed.

## Part F — Final usability review
- [ ] Viewer can understand the report's purpose quickly.
- [ ] Reading order is obvious.
- [ ] KPI cards and key visuals stand out.
- [ ] Slicers and navigation are easy to use.
- [ ] Page is not overcrowded.
- [ ] All visuals contribute to a business question.
- [ ] PBIX saved successfully.
