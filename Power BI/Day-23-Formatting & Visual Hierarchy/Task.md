## Part C — Format labels and values
- [x] Format sales values consistently (currency or appropriate numeric format).
- [x] Use consistent decimal places.
- [x] Ensure axis labels and category names are readable.
- [x] Enable data labels only where they help.
- [x] Fix overlapping or clipped labels.
- [x] Use a currency symbol only when supported by the dataset/business context.

## Part D — Arrange the report
- [x] Place the Total Net Sales card near the top.
- [x] Put the main category comparison and monthly trend in the next row.
- [x] Place supporting visuals below or on a second page.
- [x] Align visual edges where possible.
- [x] Keep spacing between visuals consistent.
- [x] Check that visuals do not overlap or extend beyond the page.

## Part E — Create visual hierarchy
- [x] Make the primary KPI easy to find.
- [x] Make main analysis visuals more prominent than supporting detail.
- [x] Use a small, consistent color palette.
- [x] Keep fonts consistent.
- [x] Remove unnecessary gridlines, legends, borders, or decoration where they do not help.
- [x] Leave enough whitespace to avoid a crowded page.

## Part F — Answer these review questions
1. What is the most important KPI on your page?
2. Which visual should the viewer look at next, and why?
3. Which formatting change improved readability the most?
4. Did you remove any unnecessary visual element? What was it?
5. Is every visual necessary to answer a business question?

## Part G — Final validation
- [x] Page can be understood quickly.
- [x] Titles are descriptive and consistent.
- [x] Numbers are formatted consistently.
- [x] Reading order is obvious.
- [x] Visuals are aligned and readable.
- [x] No labels are clipped or overlapping.
- [x] PBIX is saved.
