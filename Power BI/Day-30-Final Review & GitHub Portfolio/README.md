## Part 1 — Final report quality check

### Data and model
- Verify the dataset source and row count (the learning dataset contains 1,500 rows).
- Check data types, blank/error values, and key fields.
- Review relationships and confirm the date relationship works if a date table is used.
- Confirm the main measures return sensible values.
- Test at least one filter and confirm the measures respond.

### Dashboard
- Confirm the report title and KPI labels are clear.
- Check number formats, units, and date labels.
- Ensure charts have useful titles and appropriate visual types.
- Check that month labels are chronological.
- Remove unused visuals and unnecessary decoration.
- Test slicers, bookmarks/buttons, drill-down, drill-through, Back button, and tooltips that are included.

### Business insights
Review your three Day 29 insights:
- Are they supported by actual values or patterns?
- Do they name the visual or filter context?
- Do they avoid unsupported causal claims?
- Does each insight lead to a useful question or action?
